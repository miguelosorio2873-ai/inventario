MANUAL DE USUARIO DETALLADO

Sistema de Gestión de Inventario Pro

1. Introducción y Propósito

Inventario Pro es un sistema integral moderno, diseñado con tecnología FlatLaf (Dark Mode), que centraliza la administración operativa y financiera de tu negocio. El sistema permite gestionar un catálogo de productos multimoneda, llevar control de stock, emitir facturación y procesar reportes en tiempo real.

2. Acceso y Perfiles de Usuario

Inicio de Sesión

Al ejecutar el sistema, serás recibido por la pantalla de inicio de sesión segura. Deberás ingresar tu Correo Electrónico y Contraseña.

Perfiles de Acceso (Roles)

El sistema protege la información confidencial mediante un esquema de roles asignados desde la creación de cada usuario:

👑 Administrador

Posee control total del sistema. Puede configurar la Tasa de Cambio, crear nuevos usuarios, eliminar registros importantes y ver historiales globales y reportes.

👤 Usuario Estándar

Acceso diseñado para cajeros y personal de almacén. Permite registrar ventas, visualizar productos y modificar el stock, pero restringe la alteración de configuraciones críticas o la gestión de usuarios.

3. Dashboard Principal (Inicio)

Una vez dentro del sistema, el **Dashboard** funge como tu central de métricas operacionales. Ofrece información al instante:

  • Métricas Generales: Tarjetas superiores con el conteo de Productos Totales, Clientes Registrados, Productos con Stock Bajo y las Ventas del Mes.
  • Gráficas en Vivo: Un gráfico de barras interactivo que clasifica el *Top 5 de Productos con Mayor Stock*.
  • Alertas de Stock: Una tabla dedicada que muestra los productos cuyo stock actual ha caído por debajo de su límite de emergencia o *Stock Mínimo*.

4. Gestión de Catálogo y Sistema Multimoneda

Módulo de Productos

Desde este panel podrás visualizar todo tu inventario. Cuenta con una barra de búsqueda rápida por SKU o Nombre.

  • Precio Multimoneda Dinámico: Al registrar o visualizar un producto, el sistema muestra su precio tanto en Dólares (USD) como en Bolívares (VES).
  • Cálculo Automático: Durante la creación/edición de un producto, al escribir el precio en USD, una etiqueta verde mostrará instantáneamente la conversión exacta calculada con la Tasa de Cambio activa.

Módulo de Categorías

Permite agrupar los artículos (ej. Herramientas, Víveres, Electrónica). Cada producto debe enlazarse obligatoriamente a una de estas categorías para mantener el orden.

5. Operaciones de Inventario y Movimientos

El módulo Inventario es el corazón de la logística. Ningún producto cambia su cantidad mágicamente; todo requiere un movimiento rastreable:

  1. Entrada: Se suma stock (por ejemplo, al recibir mercancía de un proveedor).
  2. Salida: Se resta stock (utilizado para mermas o despachos manuales).
  3. Ajuste: Reemplaza el stock actual por un número exacto tras un inventario físico.

6. Facturación y Ventas

El panel de Facturación es ideal para la atención al cliente:

  • Panel de Compra: Busca y añade productos al carrito. El sistema suma automáticamente los montos y previene vender productos cuya cantidad solicitada sea superior al stock existente.
  • Vínculo con Cliente: Permite seleccionar a un cliente previamente guardado en el Módulo Clientes.
  • Cierre de Factura: Al procesar la venta, el sistema reduce automáticamente el stock del inventario y registra las ganancias del día.

7. Configuración General

Moneda y Tasa de Cambio: En el panel de Configuración, puedes ajustar la Tasa de Cambio (Bolívares por Dólar). Al actualizar este valor, ¡todos los precios mostrados en Bolívares en el sistema se actualizarán inmediatamente a nivel global!

Aquí también es posible modificar datos fiscales del negocio (Nombre de Empresa, RIF, Teléfono) que se imprimen en los reportes o facturas.

8. Reportes y Respaldo

Finalmente, el sistema provee herramientas de auditoría:

  • Reportes en Excel: Genera planillas descargables de Ventas, Clientes o Inventario, perfectas para análisis externo o contaduría.
  • Respaldo DB: Herramienta para emitir copias de seguridad de la base de datos completa.
